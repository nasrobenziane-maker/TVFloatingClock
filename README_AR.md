# TV Floating Clock — مشروع Android

مشروع أولي لساعة عائمة على Google TV:
- ساعة رقمية وتاريخ.
- محاولة عرض اسم شبكة Wi-Fi.
- نافذة عائمة قابلة للتحريك.
- إعداد للتشغيل التلقائي عند بدء التلفاز.
- بناء APK عبر GitHub Actions دون تثبيت Android Studio محليًا.

## بناء APK أونلاين
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع جميع ملفات هذا المشروع إلى المستودع.
3. افتح تبويب Actions وفعّل Actions إن طُلب ذلك.
4. شغّل `Build TV Floating Clock APK` عبر Run workflow، أو ادفع commit إلى فرع `main`.
5. افتح نتيجة التشغيل الناجح، ثم نزّل Artifact باسم `TVFloatingClock-debug-apk`. داخله `app-debug.apk`.

## التثبيت على Google TV
1. انقل APK إلى التلفاز وثبّته بالطريقة التي يسمح بها التلفاز.
2. افتح التطبيق.
3. اختر السماح بالعرض فوق التطبيقات، وفعّل الإذن من إعدادات Android.
4. ارجع للتطبيق واضغط «تشغيل الساعة الآن».
5. اترك خيار التشغيل التلقائي مفعّلًا إذا أردت تجربته بعد إعادة التشغيل.

## قيود مهمة
- هذا مشروع أولي، وليس APK تم بناؤه أو اختباره على تلفاز STREAM R6G.
- بعض إصدارات Google TV تمنع عرض النوافذ العائمة أو بدء الخدمات تلقائيًا بعد الإقلاع.
- Android قد يخفي اسم Wi-Fi بسبب سياسة الأذونات أو إعدادات الموقع. عندها سيظهر تنبيه بدل اسم الشبكة.
- يمكن تحريك الساعة بالريموت عبر تفعيل خيار التحريك ثم استخدام الأسهم (24 بكسل لكل ضغطة)، ويوقف زر OK هذا الوضع. كما يمكن اختيار واحد من أركان الشاشة الأربعة أو استخدام السحب باللمس/الفأرة.
- تتضمن إعدادات المظهر الرمادي الفاتح والغامق، وشفافية الخط بخطوات 10٪؛ ويتغير لون زر الركن المحدد إلى درجة أغمق عند انتقال التركيز إليه.
- التطبيق يستهدف API 28 لتقليل تعقيدات التوافق أثناء النموذج الأولي. يلزم اختبار الجهاز الفعلي قبل اعتباره إصدارًا نهائيًا.
